# Что нашлось в коде и данных игры

Находки, сделанные по ходу восстановления исходников. Код движка лежит в этом репозитории —
на него даны ссылки. Скрипты, звуки и модели — это данные игры из вашего `QUEST.ezd`, в
репозиторий они не входят, поэтому указаны только имена файлов.

## Секреты и вырезанное

- **Пароль «GOD».** Компьютер у ворот (`comp_vorota.scv`) ждёт три буквы: G → O → D. Ввод
  проверяется только после третьей буквы. После второй неудачной попытки включается реплика кота
  (`comment_cat_8.ogg`), видимо подсказка. Верный пароль открывает сразу шесть дверей.
- **Поздняя правка выхода из реактора.** В архиве две версии `reaktor_exit.scv`. В первой выйти
  из реактора можно было, только если у Антона есть банка титбита. Во второй это условие убрано, и
  выход открыт всегда. Движок берёт последнюю запись с таким именем
  ([`editor/formats.py`](../editor/formats.py#L62)), так что работает исправленная версия. Похоже,
  игроки застревали, и это залатали дописыванием файла в конец архива, а не пересборкой.
- **Вырезанное видео в реакторе.** Скрипт `reaktor_video.scv` проигрывал `acid.avi` прямо на
  3D-плоскости внутри уровня, со звуком `powerplant_acid_cry.ogg`. После ролика он передавал
  слово Дане (`danya_dialog`). Этот скрипт нигде не подключён.
- **Обойма в подворотне.** Есть скрипт подбора патронов (`podvor_obojma.scv`), модель обоймы
  (`podvorotniaOboima.meat`), звук `sound_obojma.ogg` и модель `vxodgun.meat` («пистолет у
  входа»). Ничего из этого сцены не используют. Похоже на вырезанную ветку с оружием.
- **Неиспользуемые звуки:** `circular_pila.ogg` (циркулярная пила, в тегах подписан уровнем
  `lab03`), `maloy.ogg`, `bullet_podval.ogg`.
- **Пять флагов квестов из первоначального плана.** Они объявлены в заголовке `queststate`, но ни
  один скрипт их не трогает: `quest_get_compr_fotos`, `quest_get_compr_tape`,
  `quest_bring_fetishes`, `quest_bring_pornodisk_to_janus`, `quest_get_to_hippi`. Сами эти линии в
  игре есть, просто логику в итоге сделали на других переменных.
- **Бесполезный «тройной фаллос».** Его можно взять в подвале (`an_spodval_walk.scv`), но ни один
  скрипт не проверяет его применение (номер предмета 11). В лаборатории (`anton_lab3.scv`) игра
  молча чистит инвентарь — «убираем все оставшиеся предметы» — вместе с бельём, пистолетом и
  «Беломором».
- **Сапоги, которые нельзя получить.** У `item_boots` есть иконка в инвентаре, но ни одна сцена
  их не выдаёт — вырезанный предмет.
- **Даня** — полноценный персонаж: диалоги в лаборатории и на электростанции (`danya_dialog.scv`,
  `danya_power.scv`, `danya_lab2.scv`), своя анимация разговора.

## Приколы

- **Мини-игра «Шива»** (`shiva.scv`, больше тысячи строк). Шестирукая богиня бросает листья
  конопли — функция так и называется: `THROW_CANABIS(int numhand)`, а «чувак» их ловит и теряет
  жизни.
- **Аркада `trax.scv`** со стрелками, шкалой «оргазма» и тремя анимациями (`anton_sex1..3.EZA`). У
  скорости анимации комментарий «6-50 ;-)».
- **Комментарии разработчиков** в сцене с Соней и Раскольниковым (`an_rld_walk.scv`): «тут
  приближаем камеру к Раскольникову, пиздим о жизни». В квартире 13 у сатанистов
  (`an_kv13_satan_walk.scv`) сидят Достоевский и палач.
- **Подпись команды в звуке.** У всех звуков в тегах `ARTIST=MEAT_MAT`. Это расширения форматов
  самого движка: `.meat` — модели, `.mat` — материалы. Кодировали программой oggdropXPd с libVorbis
  от 17 июля 2002 года.
- **Следы шаблона Visual C++.** В ресурсах полноэкранного квеста остались окно «About» с текстом
  «fullscreengl Application v1.0» и меню File / Edit / Help с «Print Preview» и «Cut / Copy / Paste»
  ([`titbit.rc`](../src/lanes/codex/resources/titbit.rc#L46)). Игру начинали из стандартной
  заготовки и так и не почистили.
- **Мусор из 3ds Max:** в архиве лежит `rot.bip` — файл Biped для анимации рта.
- **Ловушка в движке.** В коде строк из библиотеки WTL форматирование дробного числа через `%f`
  даже в релизной сборке вызывает `DebugBreak()`, то есть падение
  ([`archive_format.cpp`](../src/native/archive_format.cpp#L282)). Разработчики, видимо, знали и
  обходили это.

## Технические решения для 2003 года

- **Скрипты лежат в игре исходным текстом** и компилируются прямо при загрузке сцены встроенным
  компилятором [SeeR](../src/seer/README.TXT) — вызов `scCompile_Text` в
  [`script_objects.cpp`](../src/lanes/engine41/script_objects.cpp#L90). Вся логика квеста —
  около 44 тысяч строк C-подобного кода в 416 файлах `.scv`, которые можно читать и менять без
  компилятора движка.
- **Архив как система патчей.** `QUEST.ezd` ищет файлы с конца, поэтому достаточно дописать новую
  версию файла в хвост. Так в нём оказались 6 дубликатов, включая исправленный выход из реактора.
- **Видео на 3D-объектах.** `CreateAVIPlane` натягивает AVI-ролик как текстуру на плоскость в
  сцене ([`script_api.cpp`](../src/lanes/engine41/script_api.cpp#L189) — список функций, доступных
  скриптам).
- **Синхронизация губ со звуком.** Реплики связываются с анимацией рта через `SetSync`
  ([`stream_sound.cpp`](../src/lanes/engine42/stream_sound.cpp#L176)).
- **Сохранения с картинками:** шесть слотов, у каждого скриншот-превью (`loaddlg.scv`).
- **Эффект радиации одной формулой:** объект пульсирует по синусу через масштаб кости
  (`radiation.scv`), без отдельной анимации.
- **Проверка диска** искала привод с меткой тома `TITBIT`
  ([`platform_startup.cpp`](../src/native/platform_startup.cpp#L139)), а данные всё равно читала
  из папки установки.
- **Ролики:** 13 сжаты Microsoft MPEG-4 v2, 5 — Microsoft Video 1, звуковых дорожек нет ни в одном.
