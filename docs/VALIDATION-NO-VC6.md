# Сборка без VC6 — 20 октября 2026

Штатные сборки Windows и Linux не читают компилятор, заголовки или библиотеки VC6.
Обе проверены с `TITBIT_VC6`, указывающей на несуществующий каталог. Прежние EXE и
релизные архивы сохранены; новая Windows-сборка использует `build/modern-portable/`.
Команды установки инструментов: [Windows](BUILD.md), [Linux](../linux-port/docs/BUILD-LINUX.md).

## Среда и результат

| | Windows | Linux |
|---|---|---|
| Компилятор | LLVM-MinGW 20240619, Clang 18.1.8 | Ubuntu Clang/LLVM 18.1.3 |
| Системные объявления | открытые заголовки mingw-w64 | Ubuntu `mingw-w64-i686-dev` |
| C runtime | MSVC 14.44.35207 + UCRT SDK 10.0.18362.0 | нативный Linux-слой, glibc 2.39 |
| Среда проверки | Windows, скрытый рабочий стол | Ubuntu 24.04 / WSL2, отдельный Xvfb, Mesa |
| Результат | PE32, 340 модулей, LINK 0 | ELF32, 335 модулей, сборка `--minimal` |

Строки, контейнеры и используемый набор ATL реализованы в общем [portable/](../portable/README.md).
Microsoft STL/ATL, `LIBC.LIB`, `LIBCP.LIB` и reference-каталоги не нужны.
В Windows по-прежнему нужны современные C++ Build Tools и Windows SDK.

## Повторить проверки

Windows, из корня, после настройки инструментов:

```powershell
.\.venv\Scripts\python.exe tools/build_modern.py --fresh --test-runtime
$env:TITBIT_GAME = 'D:\Games\Titbit'
.\.venv\Scripts\python.exe -m unittest discover -s editor -p 'test_*.py'
.\.venv\Scripts\python.exe -m unittest discover -s tools/tests -p 'test_*.py'
```

Linux, из `linux-port/`:

```bash
TITBIT_VC6=/does-not-exist python3 tools/build_linux.py --minimal --jobs 4 --test-runtime
TITBIT_GAME=/path/to/game python3 -m unittest discover -s editor -p 'test_*.py'
python3 tools/headless_probe.py --data /path/to/test-game --frames 20000 \
  --timeout 360 --actions probes/gameplay-actions.json --gdb --out build/gameplay
```

Сценарий записывает слот 1: передайте тестовую копию игры. Самостоятельная
Linux-выгрузка создаётся через `tools/export_public.py --dest /path/to/empty-folder`.
Она содержит общий `portable/`, упаковщик и Flatpak-рецепт.

Хэши проверенных файлов, версии и пути локальных отчётов:
[validation-no-vc6.json](validation-no-vc6.json). `sourceDateEpoch` фиксирует время
исходников, использованное для этих Windows EXE; другой коммит может менять PE timestamp.
Хэши Linux-ELF из двух каталогов отличаются из-за строк `__FILE__`; побайтная
воспроизводимость Linux здесь не заявляется.

Это проверка начального игрового маршрута и редактора, а не полного прохождения,
всех видеокарт и всех дистрибутивов. Исторические проценты byte-match относятся
к исходной VC6-реконструкции, не к машинному коду новых сборок.
