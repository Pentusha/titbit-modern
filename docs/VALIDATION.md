# Проверка публичного экспорта — 19 октября 2026

Это историческая VC6-сборка. Текущая проверка Windows и Linux без VC6:
[VALIDATION-NO-VC6.md](VALIDATION-NO-VC6.md).

Оба варианта прошли свежую компиляцию и реальный LINK с `TITBIT_VC6`.
Современная версия собрана из отдельной копии публичного экспорта, без `src/crt`,
OpenNT / Microsoft reference trees и оригинального EXE. Использованы установленный
на этой машине VC6 (CL 12.00.9044), его статические LIBC/LIBCP; ресурсы — `tools/rc_compile.py` (`.res` байт в байт
совпадает с выводом Windows SDK `rc.exe`, EXE — во всех секциях).
Это проверка независимого дерева исходников на этой машине, а не чистой установки ОС.

Тесты импорта проверяют отмену, повреждённые данные, недостаток места,
сохранность исходника и сохранений, отказ перезаписывать изменённые файлы.
Тест упаковки подмешивает игровые данные и сохранения в папку сборки:
в итоговый ZIP они не попадают. Полное сравнение содержимого ISO и IMG
с сохранённой копией диска также выполнено отдельно.
Скриншот Studio, предоставленный владельцем проекта, включён без изменений.

Финальная проверка: файлы из индекса Git выгружены в новую папку без игровых
скриптов, старых ICO, закрытых reference-каталогов и артефактов сборки.
Свежая компиляция всех модулей и LINK завершились успешно с зависимостями
из `requirements.txt` и установленным VC98. Отличающиеся SHA256 этой сборки
и проверенного portable-EXE записаны раздельно в отчёте.

Подробности и SHA256 EXE/библиотек: [validation.json](validation.json).
Хеши относятся к этому прогону: старый toolchain не гарантирует одинаковый EXE
при изменении времени сборки, пути или версии установленного VC6.

![Улица из проверенной публичной сборки](images/game-street.png)

Это не проверка полного прохождения игры, всех GPU/версий Windows либо совпадения
всего EXE с оригиналом. Оригинальная версия собрана без совместимости; её запуск
в этой проверке не выполнялся. Исходные диски, рабочая игра и сохранения не изменялись.
