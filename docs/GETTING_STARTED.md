# Как запустить игру

> [!IMPORTANT]
> **Нужна ваша копия «Ядерного Титбита»:** оригинальный CD, образ диска (ISO / IMG / CUE / CCD)
> или установленная игра. Без неё игра не запустится — данные игры не входят в пакет.

Нужны Windows 10/11 x64 и portable-пакет из Releases. Python, компилятор и интернет не нужны.

## 1. Подготовьте папку

Скачайте portable-пакет из [Releases](https://github.com/offx366/titbit-modern/releases)
и распакуйте, например в **`C:\Games\TitbitModern`**.
Оставьте его файлы вместе. Выберите папку, в которую у вас есть право записи:
туда будут добавлены игровые данные, настройки и сохранения.

| Программа | Назначение |
|---|---|
| **TitbitSetup.exe** | Добавить или проверить данные своей игры |
| **TitbitSettings.exe** | Настроить экран и запустить игру |
| **TitbitModern.exe** | Запустить игру напрямую |
| **TitbitStudio.exe** | Открыть локальный редактор сцен |

## 2. Выберите источник данных

Запустите **TitbitSetup.exe** (или сразу **TitbitModern.exe** — без данных игры он сам откроет
TitbitSetup) и выберите один из вариантов ниже.

Если Windows покажет «Windows защитила ваш компьютер», нажмите **«Подробнее» → «Выполнить в любом случае»**.

Папка назначения — ваша папка Titbit Modern, рядом с `TitbitModern.exe`.

### Уже установленная игра

Укажите папку установленного «Ядерного Титбита», например `D:\Games\Titbit`.
Утилита ищет `QUEST.ezd` и видеоролики в ней и вложенных папках.
Копировать старую игру целиком поверх современной сборки не нужно.

Если у вас репак с отдельным установщиком, сначала установите его в другую
папку, затем выберите эту папку как источник. Произвольные форматы репаков
не поддерживаются как образы оригинального диска.

### Оригинальный CD

Вставьте диск и выберите его привод. Утилита прочитает данные с диска,
включая поддерживаемые установочные архивы InstallShield 6.
Запускать старый установщик или ставить его кодеки не требуется.

### ISO, IMG, CUE или CCD

Выберите файл образа. Поддерживаются ISO с секторами 2048 байт и сырые
CD-образы IMG с секторами 2352 байта, в том числе описанные CUE/CCD.
Файлы одного набора (`.img`, `.cue`, `.ccd`) держите в одной папке
и не переименовывайте по отдельности.

Данные читаются напрямую: монтирование образа и виртуальный привод не нужны.
`.sub` содержит субканальные данные диска; для игровых ресурсов он не требуется.

## 3. Импортируйте и проверьте

После проверки источника нажмите **«Добавить файлы игры»** и дождитесь
завершения. В папке назначения должны появиться:

```text
TitbitModern/
  TitbitModern.exe
  TitbitSettings.exe
  TitbitSetup.exe
  TitbitStudio.exe
  QUEST.ezd
  ... 18 файлов AVI
```

Утилита не меняет исходную копию игры и не переносит сохранения. Совпадающие
файлы можно использовать повторно. Если файл назначения отличается, импорт
не заменяет его: проверьте источник или выберите пустую папку.
При отмене повторите импорт в ту же папку — уже проверенные файлы останутся.

Для проверки имеющейся установки укажите её папку в поле назначения
и нажмите **«Проверить готовую папку»**.
После успешного импорта диск или образ больше не нужен для обычного запуска.

## 4. Запустите игру

Откройте **TitbitSettings.exe**, выберите размер окна и режим масштабирования,
затем запустите игру. Позже можно открывать **TitbitModern.exe** напрямую.

- **Alt+Enter / F11** — окно / полный экран.
- **4:3** — исходные пропорции с полями; растяжение заполняет экран.
- Громкость настраивается в меню самой игры.
- Сохранения создаются в папке используемой установки; из другой папки
  они автоматически не переносятся.

## 5. Редактор сцен

**TitbitStudio.exe** из той же папки откроет браузер с редактором (адрес показан в окне Studio).
Оригинальные файлы он не меняет. Подробно: [руководство редактора](../editor/README.md).

## Если что-то не получилось

| Сообщение или симптом | Что проверить |
|---|---|
| QUEST.ezd не найден | Выберите папку игры, корень CD или весь образ, а не один EXE |
| Найден архив, но нет части AVI | Выберите исходный диск/полную установку; в урезанном репаке роликов может не быть |
| Файл назначения отличается | Это может быть другая версия или мод. Сохраните его и используйте пустую папку |
| Образ не распознан | Проверьте комплект IMG/CUE/CCD; для другого формата используйте установленную игру |
| Нет прав на запись | Распакуйте пакет в свою папку, например C:\Games\TitbitModern |
| Studio не открывается | Дождитесь запуска сервера и нажмите кнопку открытия браузера в окне Studio; используйте показанный там адрес |

Для сообщения о проблеме укажите версию Windows, тип источника данных и текст
ошибки. Игровые архивы, образы и сохранения публично прикладывать не нужно.
