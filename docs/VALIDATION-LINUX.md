# Linux preview 1 — область проверки

Среда: Ubuntu 24.04 / WSL2, x86-64, библиотеки i386; SDL2, Mesa OpenGL,
FFmpeg 6.1. Выходной файл — нативный ELF32/i386. Wine и оригинальный EXE
не используются. Игровые данные импортируются из пользовательской копии.

| Проверка | Результат |
|---|---|
| Сборка из очищенного публичного дерева | 335 рецептов; 334 ELF-объекта и отдельная нативная реализация SeeR callasm |
| CRT/C++ | COW-строки, типизированные исключения, RAII, locale, FILE32, потоки и 64-битные файловые позиции — PASS |
| Начальная игра под GDB | 20 000 кадров: ролики, меню, улица, ходьба, анимация, диалог, сохранение и загрузка; штатный выход |
| Повторный прогон с захватом PCM | 9 000 кадров, 67,44 с, штатный выход; 11 124 736 байт реального игрового PCM |
| Аудиовыход WSLg | Нативный ELF32 открывает PulseAudio и завершает буфер тишины; проверен автоматический выбор драйвера |
| Studio, Python 3.12 | 28 тестов; 455 EZA-клипов, 314 моделей, 161 материал, 70 сцен |
| Studio, HTTP | Все 70 сцен; модели, EZA, PNG-текстуры, запись проекта, отказ стороннему Origin; SHA256 оригинального архива не изменился |
| Studio, браузер | Linux-сервер в WSL: сцена клуба, выбор персонажа, рамка в камере игры, анимация/пауза, инспектор, сохранение |
| Импорт ISO | 19 файлов / 311 181 440 байт, SHA256 совпадают; Tk-мастер проверен в отдельном Xvfb |

Для GUI-проверки Studio использован браузер Windows, подключённый к серверу
Ubuntu через localhost. Нативные Firefox/Chromium разных Linux-дистрибутивов
отдельно не проверялись. Аудиопроверка разделена на запись настоящего игрового
PCM и вывод тишины через PulseAudio; это не отчёт о прослушивании динамиков.

## Повторение

Из `linux-port/` исходников или корня распакованного Linux-пакета:

```bash
TITBIT_GAME=/path/to/game python3 -m unittest discover -s editor -p 'test_*.py' -v
python3 tools/tests/check_studio_http.py --archive /path/to/game/QUEST.ezd --report /tmp/studio-http.json
python3 -m unittest discover -s tools/tests -p 'test_*.py' -v
```

Инструкции запуска игры без видимых окон и сценарии проверки:
[probes/README.md](../linux-port/probes/README.md).
Регрессионный игровой сценарий записывает слот 1 — нужна отдельная тестовая папка.

## Ограничения

- Проверен начальный участок игры; полного прохождения нет.
- Проверена Ubuntu 24.04 x86-64 / WSLg; ARM64 и остальные дистрибутивы не заявлены.
- Linux запускается в окне 1024×768. Alt+Enter/F11 и панель Windows-настроек пока относятся к Windows.
- Внешние документы через `ShellExecute` в Linux не открываются.
- Поддерживается исходный набор данных версии 1.00. Произвольные repack `setup.exe` не распаковываются.
- SDL `disk` с выходом на проверенный `/mnt/c` не поддерживается как игровой драйвер;
  для диагностики используется `TITBIT_AUDIO_CAPTURE_DIR`, без смены обычного аудиодрайвера.
