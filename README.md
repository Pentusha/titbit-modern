Восстановленная версия **«Ядерного Титбита»** (VZlab / Бука, 2003).
Игровая логика сохранена в основном движке, дополнения для современных Windows
вынесены в `src/compat/`.

## Как играть

**Нужна собственная копия игры: установленная папка, оригинальный диск или его образ.**
Игровые данные в репозиторий и portable-пакет не входят.

1. Скачайте portable-пакет из [Releases](https://github.com/offx366/titbit-modern/releases) и распакуйте, например в `C:\Games\TitbitModern`.
2. Откройте **TitbitSetup.exe**, выберите свою копию игры и импортируйте данные.
3. Запустите **TitbitSettings.exe** для настройки экрана или **TitbitModern.exe** для игры.

В готовом пакете не нужны Python, компилятор, интернет или установка старых кодеков.
После импорта диск можно убрать. Музыка, озвучка, модели и уровни читаются из ваших данных.
Подробно: [папка игры, диск и образ](docs/GETTING_STARTED.md).

## Возможности

- **Полный экран без смены видеорежима** — переключение через **Alt+Enter / F11**.
- **Размер окна и масштабирование** — пропорции 4:3 или растяжение, корректные координаты мыши при изменении масштаба и DPI.
- **Отдельные настройки экрана** — TitbitSettings; громкость меняется в меню игры.
- **Старые видео на новых Windows** — MP42 через Media Foundation, встроенный декодер CRAM.
- **Свои данные без диска в приводе** — импорт из папки, CD, ISO или IMG/CUE/CCD.

## Titbit Studio

Локальный редактор сцен: запустите **TitbitStudio.exe**, браузер откроется
автоматически (обычно **http://127.0.0.1:4318/**). Studio использует
`QUEST.ezd` рядом с программой; интернет не нужен.

![Titbit Studio — сцена клуба и выделенный персонаж](docs/images/studio.png)

- **70 локаций**, игровая камера 4:3 и свободный обзор сцены.
- Выбор объектов, перемещение, поворот, масштаб, привязка, отмена и повтор.
- Геометрия, материалы, кости, свойства, XML и просмотр оригинальных скриптов.
- Родные **EZA-анимации**: сцена или объект, пауза, перемотка, скорость и цикл.
- Экспорт **OBJ + MTL + PNG / GLB**, импорт статических **OBJ / GLB / glTF**.
- Собственные проекты, копии локаций, замена моделей и экспорт изменённого архива.

Оригинальный архив открывается только для чтения. Правки сохраняются отдельно.
Studio показывает ресурсы сцены, но не запускает игровую логику и диалоги.
GLB экспортирует текущую статическую позу; импорт скелетных анимаций и FBX не поддерживается.
Управление и ограничения: [руководство Studio](editor/README.md).

## Сборка из исходников

Нужны Python 3.11 и собственная установка **Visual C++ 6.0 SP6** с MASM,
а также Resource Compiler из Windows SDK. Инструменты Microsoft не включены.

```powershell
$env:TITBIT_VC6 = 'C:\Program Files (x86)\Microsoft Visual Studio\VC98'
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe tools/build_modern.py --fresh
```

EXE появится в `build/modern/`. Полные команды для игры, Studio, импорта данных
и portable-пакета — [docs/BUILD.md](docs/BUILD.md).

## Состояние проекта

Современная сборка проверена до первой улицы с обработкой кликов.
Тесты Studio охватывают все 70 XML-сцен, 314 MEAT-моделей, 161 MAT-материал
и 455 EZA-анимаций исходного архива. Полное прохождение и все сочетания Windows/GPU
не проверены. Условия и результаты: [docs/VALIDATION.md](docs/VALIDATION.md).
