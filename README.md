Реконструкция исходного кода **«Ядерного Титбита»** по оригинальному исполняемому
файлу. Репозиторий содержит код игрового движка, отдельный слой совместимости
с современными Windows и инструменты для работы с ресурсами игры.

Движок собирается в **32-разрядный Win32 EXE** с помощью Visual C++ 6.0.
Дополнения для Windows 10/11 находятся в `src/compat/` и подключаются через
`TITBIT_COMPAT`. Вариант без этого слоя собирается отдельно.

## Структура проекта

| Каталог | Содержимое |
|---|---|
| `src/lanes/`, `src/native/` | Восстановленный код и структуры движка |
| `src/compat/` | Совместимость с современными Windows и настройки запуска |
| `editor/` | Titbit Studio: локальный сервер, редактор сцен, обработка форматов |
| `tools/` | Сборка, импорт данных с диска, подготовка portable-пакета |
| `config/` | Рецепты сборки, таблицы символов, размеры и хеши ресурсов |
| `docs/` | Инструкции, результаты проверок и сведения о зависимостях |

## Сборка

Требуются **Windows 10/11 x64**, **Python 3.11**, собственная установка
**Visual C++ 6.0 SP6** с MASM и **Resource Compiler** из Windows SDK.
C/C++ runtime и STL используются из установленного VC98: `LIBC.LIB`,
`LIBCP.LIB` и штатные заголовки. Инструменты Microsoft в репозиторий не входят.

```powershell
$env:TITBIT_VC6 = 'C:\Program Files (x86)\Microsoft Visual Studio\VC98'
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe tools/build_modern.py --fresh
```

Результат: `build/modern/TitbitModern.exe` и `TitbitSettings.exe`.
Для сборки варианта без `TITBIT_COMPAT`:

```powershell
.\.venv\Scripts\python.exe tools/build_original.py --fresh
```

Оригинальный EXE для сборки не требуется. Подготовка toolchain, запуск Studio
из исходников и упаковка программ: [docs/BUILD.md](docs/BUILD.md).

## Запуск

Готовые программы доступны в [Releases](https://github.com/offx366/titbit-modern/releases/tag/v0.1.0).
Для них не требуется установка Python или компилятора.

**Необходимы данные собственной копии игры.** Архив `QUEST.ezd` содержит уровни,
модели, текстуры, анимации, скрипты, музыку и озвучку; видеоролики хранятся
в 18 отдельных AVI. Эти файлы не включены в распространяемый пакет.

1. Распакуйте portable-пакет в отдельную папку.
2. Запустите `TitbitSetup.exe` и укажите установленную игру, оригинальный CD
   или образ ISO/IMG/CUE/CCD. Мастер извлечёт данные и проверит SHA256.
3. Откройте `TitbitSettings.exe` для настройки экрана или `TitbitModern.exe`
   для запуска игры.

Образы читаются напрямую, без монтирования и запуска старого установщика.
Поддерживается полный оригинальный набор данных версии 1.00.
После импорта диск в приводе не требуется.
[Инструкция по импорту и запуску](docs/GETTING_STARTED.md).

## Слой совместимости

- Оконный и полноэкранный режимы без переключения видеорежима монитора;
  **Alt+Enter / F11** для переключения.
- Масштабирование с сохранением 4:3 или растяжением; преобразование координат
  мыши с учётом размера окна и DPI.
- Декодирование MP42 через Media Foundation и встроенный декодер CRAM.
- Загрузка ресурсов из локальной папки; отдельная программа настройки экрана.

## Titbit Studio

Редактор сцен с браузерным интерфейсом и локальным сервером Python.
`TitbitStudio.exe` запускает сервер и открывает браузер; стандартный адрес —
**http://127.0.0.1:4318/**. Зависимости включены в EXE, сетевые сервисы не используются.

![Titbit Studio — редактирование сцены клуба](docs/images/studio.png)

- Загрузка **70 локаций** из `QUEST.ezd`, исходная игровая камера и свободный обзор.
- Выбор объектов, перемещение, поворот, масштабирование, привязка, undo/redo.
- Просмотр геометрии, материалов, костей, свойств объектов, XML и скриптов.
- Воспроизведение **EZA-анимаций**, перемотка по времени, скорость и зацикливание.
- Экспорт **OBJ + MTL + PNG** и **GLB**; импорт статических **OBJ / GLB / glTF**.
- Отдельные файлы проектов, замена моделей, создание копий сцен и экспорт
  изменённого игрового архива.

Исходный архив открывается только для чтения. Studio воспроизводит ресурсы
и анимации сцены; игровая VM и диалоги в редакторе не выполняются.
GLB сохраняет текущую статическую позу. Импорт скелетных анимаций и FBX
не реализован. [Руководство редактора](editor/README.md).

## Проверка реализации

Проверены свежая сборка из публичного дерева исходников, импорт полного набора
данных из образа диска и запуск игры по сценарию
**меню → новая игра → интро → улица → перемещение персонажа**.

Тесты форматов охватывают **70 XML-сцен, 314 MEAT-моделей, 161 MAT-материал
и 455 EZA-анимаций** оригинального архива. Полное прохождение, все конфигурации
Windows/GPU и побайтное совпадение всего EXE с оригиналом не подтверждены.
Подробные результаты: [docs/VALIDATION.md](docs/VALIDATION.md).
