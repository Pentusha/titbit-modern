# Титбит Studio

Веб-редактор оригинальных сцен «Ядерного Титбита»: камера игры и свободный обзор,
инспектор объектов, преобразования, анимации EZA, импорт статических моделей,
экспорт OBJ/GLB и отдельных модифицированных архивов.

```sh
sh tools/start_studio.sh --archive /path/to/QUEST.ezd
```

Запускать из корня Linux-порта. Оригинальный архив открывается только для чтения.
Проекты сохраняются отдельно, в пользовательском каталоге данных.

[Установка, импорт диска, управление и проверки](../docs/STUDIO.md)
Для Linux используйте `sh tools/start_studio.sh` из корня Linux-пакета или
`linux-port/` исходников. [Linux: установка, данные и Studio](../docs/STUDIO.md).
