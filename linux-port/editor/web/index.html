Исходное описание / скрипт
Исходные ресурсы доступны только для чтения. Редактируется копия сцены; экспорт — отдельные файлы.




Экспорт сцены
GLB — текущая поза с текстурами, без анимационных дорожек. OBJ — исходная XML-поза. Пакет проекта содержит изменённый QUEST.ezd и сохраняет исходные свойства для игры. Оригинальный архив не меняется.


Свойства объекта
Поля из оригинального XML. Имена ссылок и скриптов важны для логики игры. Изменения применяются к проекту и доступны для отмены.

Сцена из копии
Текущая локация станет основой новой сцены. Геометрия, объекты и скрипты сохранятся. Новая локация не подключается к игровым переходам автоматически.
Латинские буквы, цифры, дефис и подчёркивание; расширение .xml.
