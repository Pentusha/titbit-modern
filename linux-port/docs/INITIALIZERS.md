# Инициализация глобальных объектов

ELF исполняет `llvm.global_ctors` через `.init_array`. Таблица Windows
`.CRT$XCU` из `data/cxx_startup.c` в Linux не подключается: её полный повторный
вызов сбросил бы уже сконструированные Scene, picking, архивы и XML-строки.

Восемь восстановленных объектов хранятся в POD без автоматического конструктора.
`platform/game_initializers_ms.cpp` вызывает их исходные функции один раз перед
игровым циклом, сохраняя относительный порядок:

| Адрес исходного callback | Объект | Проверяемый эффект |
| --- | --- | --- |
| `00406970` | Кэш walk areas | Шаг роста 5, пустой массив, регистрация очистки |
| `00413f90` | Кэш анимаций | Шаг роста 5, пустой массив, регистрация очистки |
| `00421500` | Кэш текстур | Установка таблицы виртуальных методов, регистрация очистки |
| `00421540` | Кэш ресурсов | Таблица методов, пустой массив, шаг 10, очистка |
| `00421580` | Renderer | `zoom=1`, `fov=40`, `next_light=0x4000`, очистка |
| `004215d0` | Матрица сцены | Единичная матрица 4×4 |
| `00427d70` | Банк звуков | Таблица методов, шаг 5, пустой массив, очистка |
| `004298d0` | Активные потоки | Обнуление четырёх полей и регистрация освобождения |

Полная классификация всех 176 исходных записей хранится в
`config/linux-initializers.json`: 8 ручных вызовов, 68 конструкторов компилятора,
92 шаблонных guard/пустых cleanup, 1 пустая функция и 7 callback рантайма VC6.
Адреса используются как идентификаторы исследования, не как адреса исполнения.

Конструкторы из `scene_global`, `picking_global`, `skin_cache`, `quest_state`,
`archive_globals`, `audio_device_state` и `native/initializers` уже присутствуют
в LLVM IR. То же относится к статическим строкам и string pool CenterPoint XML:
их lifetime задают исходники `cpx43_*`/`cpx_*`, не ручные `sax_names`-обёртки.
Их повторная placement-конструкция не выполняется.

Пропущенные шаблонные callback оригинала выставляют guards и регистрируют пустые
деструкторы. Семь callback VC6 относятся к его CRT/STL startup/teardown;
Linux использует glibc и авторский адаптер типов VC6. Windows CRT здесь не запускается.
